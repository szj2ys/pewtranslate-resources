Make the next review useful

  1. Resolve parsing problems. An error or unsupported feature means this review is incomplete. Keep the original file and check it in your subtitle editor.
  2. Use the issue time to find the cue. Watch it with the surrounding video. Shorten or re-time a caption only after checking that the words and speaker still match.
  3. Check what numbers cannot. Confirm names, meaning, speaker identification and relevant sounds. Ask the intended audience whether the captions are usable.

Supported syntax, counting method and limits

SRT: a numeric cue index, a timing line such as 00:01:02,345 --> 00:01:05,678, then plain text. Separate cues with blank lines. Hours have at least two digits; minutes and seconds run from 00 to 59.

WebVTT: a WEBVTT header, a blank line, optional single-line cue identifiers, timing with a decimal point (hours optional), and plain text. NOTE blocks are counted and skipped. This tool does not validate the whole WebVTT specification.

Reported as unsupported: STYLE, REGION, header metadata, cue settings, markup, entities and embedded timestamps. Text metrics are skipped for marked-up or structurally ambiguous cues. Unsupported features are not necessarily invalid subtitles. See the W3C WebVTT specification for the full format.

Counts: Unicode code points, including spaces and punctuation. Line breaks do not count toward characters per second. This is not a count of perceived letters, words or display width; emoji sequences and combining marks can count as several characters. Playback wrapping is not simulated. Reading rate is characters divided by cue duration.

Limits: 2 MiB of UTF-8 text, 5,000 blank-line-separated blocks and 30,000 lines. Files above a limit are rejected in full. At most 200 issue rows are displayed; CSV includes all issues from the accepted input. No media playback, translation, automatic repair or accessibility certification is provided.

CSV: every field is quoted; quotes and line breaks are escaped. Formula-like cells receive a leading apostrophe, including cells with leading spaces or controls. This intentionally changes those exported cells for safer spreadsheet use. Source text in the editor is untouched.
