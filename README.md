# PewTranslate resources collection

Pinned distribution copies of 13 existing free resources for language planning, text review, audio preparation and reproducible data inspection. Open `index.html`, then choose a resource. Interactive browser tools run locally; Python recipes have their own documented runtime requirements.

## Source and maintenance

`source-manifest.json` maps every copied file to its original project, accepted hash and byte count. Original project licenses and third-party attribution remain in place. The collection does not automatically track upstream changes. To update it, review the new source version, copy only its approved public allowlist, refresh the manifest, and test the actual subpath workflow and downloads before publication.

Copied files are unchanged. In particular, the service planner keeps its original canonical URL, and the Census reader keeps its pinned original-repository downloads. This is a distribution collection, not a migration or an independent edition of those tools. Original websites remain available.

## Privacy and limits

There is no collection analytics, account, input upload or external script. Each tool documents its own supported syntax and bounds. Inspect outputs with appropriate human judgment; these tools do not provide translation, certification or an accuracy guarantee. Original code and explanatory material were developed with AI assistance. PewTranslate live-translation accounts are closed.

## Hosting

The initial deployment is the dedicated project at `https://szj2ys.github.io/pewtranslate-resources/`. It does not configure an account-level user-site domain. No `CNAME` is included in this stage; a proposed first-party hostname is not available until its separate DNS, domain-verification and HTTPS checks succeed.
